# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.8.70 | yes |
| < 1.8.70 | no |

Only 1.8.70 is supported. Its generated types are the TDLib 1.8.69 schema. Older crates.io releases (`1.8.69`, `1.8.1`, and the `0.8.x` snapshot line) are not.

## Reporting a vulnerability

Report security issues privately through [GitHub Security Advisories](https://github.com/fewensa/rtdlib/security/advisories/new).

Please do not open a public GitHub issue for a suspected vulnerability.

Include the crate version, what the issue affects, and a reproduction if you have one. The maintainer will acknowledge the report, work on a fix, and coordinate a public advisory when a release is ready.

Private vulnerability reporting has to be enabled in the repository settings (Settings → Advanced Security → Private vulnerability reporting) before that link accepts reports.
